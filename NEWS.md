# whapi (development version)

* New carousel messages: `whapi_send_carousel()` sends a carousel of cards,
  built with `whapi_carousel_card()` and the button helpers `whapi_btn_url()`,
  `whapi_btn_quick_reply()`, `whapi_btn_call()` and `whapi_btn_copy()`;
  `whapi_validate_carousel_cards()` and `whapi_validate_carousel_buttons()`
  check them before sending.
* The README states that the package is not affiliated with Whapi.Cloud,
  WhatsApp or Meta.
